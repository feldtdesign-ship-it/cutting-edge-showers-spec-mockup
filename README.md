# Cutting Edge Glass: showers site, specification-sheet design

**Mockup for review. Not for publication.** The homeowner sister of `../glass-alt-spec`.

## The idea
The same document as the commercial spec sheet (Section 08 80 00, Glazing), written for a homeowner and set on a tile wall instead of a dark desk. Five numbered sheets: General, Layouts and glass, Before the tile goes up, Photographs, Send us a photo. The contents panel jumps to each part, and to each layout (2.01 to 2.03). "Print or save as PDF" prints the whole spec.
